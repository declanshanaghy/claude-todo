/todo pane: interactive mockup

The terminal below simulates Claude Code with the todo mod's right-hand pane. It supports only what the terminal mod API supports: a focus ring, Tab/arrows, Enter or click to press, Esc to leave. There are no hover effects and no single-letter hotkeys.
